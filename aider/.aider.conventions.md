# Aider Conventions

## What NOT to do

- Never add comments that just restate the code
- Don't refactor code outside the scope of the task
- Don't add logging unless asked to
- Never remove existing comments or docstrings

## Commit message style

- Use conventional commits: fear:, fix:, chore:, refactor:
- Keep subject line under 72 characters

## General

- Ask before making large structural changes
- Prefer editing existing files over creating new ones
- Don't install new dependencies without checking first
- Make one change at a time, don't batch multiple edits together
